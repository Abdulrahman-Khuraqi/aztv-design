# aztv-design

Homepage redesign for [aztvstore.com](https://aztvstore.com/), a Salla store. Arabic first, RTL.

- `03-current-site/old-design`: saved copy of the live homepage (reference only)
- `05-design/new-design`: the new design we are building
- `our workspace.html`: the visual project workspace
- `PROJECT.md`: project notes, the single source of truth

## View locally

Run `open old design.bat` (http://localhost:8765) or `open new design.bat` (http://localhost:8770). Both need Python.
