# Card images

The place for the photos used on the cards (players and show cut-outs). Photos arrive in batches; each batch goes in `originals/` untouched, numbered in the order received.

## Folders

- `originals/`: files exactly as supplied. Never edit them.
- `web/`: created when we start the cards. Web versions (WebP, one size per card slot, transparent background) made from `originals/`.

## Naming

`NNN-short-description.ext`, where `NNN` continues from the last number (001, 002, ...). Describe what is visible (kit, pose), not who it is.

## To check before the cards are built

- All nine are cut-outs on a **white** background (JPG, no transparency). The site is dark, so the cards need a transparent version (PNG/WebP) or the images will show a white box.
- Sizes differ (002 is 1755×2000, 009 is 928×1133, the rest about 896×1200). Crop to one aspect ratio per card slot when making `web/`.
- Rights: the photos show real people and club kits. Confirm they are licensed for the store before launch.
